## 調査範囲

提供開始発表から現在の公開サービス「ネムラナイ」へたどり、設計・実行・人の統制を確認。



公開説明と図を撮影。独立した自由操作デモ・顧客管理画面・操作動画は未確認。短縮率は提供者の主張で実測していない。

## 作業の流れ

問い合わせ → 仕様書等 → AIテスト設計 → 人の統制 → AI実行 → 結果管理 → 個別運用

## 機能の構成

サービスページに設計・実行・支援・FAQ・問い合わせ。顧客向け製品のメニュー全体は未公開確認。

下表は公開説明・文書の要約。実操作した範囲は画面一覧と調査範囲に限定し、表全体を実機検証済みとはしない。

| 段階 | 画面・機能 | 入力・操作と次の行動 |
| --- | --- | --- |
| 入力 | 開発ドキュメント | 仕様を基に設計する。文書形式・適用条件は個別確認。 |
| 設計 | AIテスト設計 | SHIFT標準のテスト設計書を生成する説明。 |
| 統制 | 専門家・AI manager | テストの専門家がAIを統制すると説明。 |
| 実行 | AIテスト実行 | テスト設計書からWebのテスト実行を支援する。 |
| 結果 | 記録・管理 | 発表ではCATへの結果蓄積を案内。現在の接続条件は確認が必要。 |
| 保守 | 案件運用 | 変更時の再設計・再実行を誰が担当するか、契約条件の確認が必要。 |
| 管理 | 権限・通知・API | 公開ページでは詳細を確認できず。 |

## 人の担当と比較上の着眼点

仕様・対象・期待と、専門家による統制の範囲を決める。

調査者の解釈：AI実行だけでなく、専門家が準備と判断を引き取る範囲が購買上の比較点。 製品性能の優劣を実証した結論ではない。
