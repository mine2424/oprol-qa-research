Tookii — 機能・導線・画面

確認日：2026年10月27日。全体比較・画面／動画ギャラリー

調査範囲

合成ユーザーを基盤にFirst Impression・A/B・Focus Group・Journey・Goal Testを使い分ける。

ページの機能・5段階説明を撮影。任意URLを入力した新規調査は未実行。装飾動画を製品操作動画として収録していない。

作業の流れ

URL・対象顧客 → 合成ユーザーを生成・編集 → 調査mode → 実行 → session replay → evidence付きfindings → 改善判断

機能の構成

Synthetic Users / First Impression / A/B Tests / Focus Group / Journey Test / Goal Test。Competitive LandscapeはComing soonの表示。

下表は公開説明・文書の要約。実操作した範囲は画面一覧と調査範囲に限定し、表全体を実機検証済みとはしない。

段階 画面・機能 入力・操作と次の行動
開始 URL・Meet your users 対象のURLから開始する入口。登録後の準備項目は未確認。
人物像 Synthetic Users 事業・顧客像を基に生成し、編集・追加・除外できると説明。
第一印象 First Impression 実browserでの最初の反応・摩擦を確認するモード。
比較・会話 A/B・Focus Group 2案への反応比較やアイデアに対する合成ユーザーの会話。
経路 Journey Test 画面ごとの進行・停止・離脱を扱う。実行方式の詳細は個別確認が必要。
目的 Goal Test 目的を与え、実browserで到達するかを調べる。
証拠 Replay・narratives 動画、人物像ごとの理由、時刻・画像に結び付いたfindingsを案内。
継続 Synthesis・次の判断 共通所見をまとめ、何を修正・出荷するか判断する。

人の担当と比較上の着眼点

顧客像の編集、テストmodeの選択、合成ユーザーの推定の妥当性を判断する。

調査者の解釈：同じ合成ユーザーが複数の調査methodを横断する。UX探索を提供する場合の比較対象。 製品性能の優劣を実証した結論ではない。
